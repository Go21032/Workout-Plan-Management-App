# 💪 筋トレメニュー管理システム

手書きメモの写真を撮るだけで、Google スプレッドシートに自動でデジタル化して記録するシステムです。

## このシステムでできること

| 機能 | 内容 |
| :---- | :---- |
| 📷 画像の自動読み取り | 手書きメモの写真をアップロードするだけでデータ化 |
| 📅 日付シートの自動生成 | トレーニング日ごとに `26/6/6` 形式のシートを自動作成 |
| 🔽 動的プルダウン | メニューリストを参照した入力規則を自動設定 |
| ✂️ データの自動整理 | カンマ区切り・L表記を検知して行を自動分割 |
| 🛡️ 既存シートの上書き防止 | 同名シートが存在する場合は日付入力画面を表示して保護 |
| 📱 スマホ対応 | WebアプリURLをホーム画面に追加してスマホからも利用可能 |

---

## システム構成

```
手書きメモ写真
      ↓
Webアプリ（GAS製）にアップロード
      ↓
OpenRouter API（AI画像認識）
      ↓
既存シートチェック
  ├─ 重複なし → Googleスプレッドシートに自動書き込み
  └─ 重複あり → 日付入力画面を表示 → 修正後に書き込み
```

- **プラットフォーム：** Google スプレッドシート（クラウド完結型・アプリインストール不要）
- **バックエンド：** Google Apps Script（GAS）
- **AI：** OpenRouter API（無料枠使用）

## 導入手順（セットアップ）

### Step 1：スプレッドシートの準備

1. [Google スプレッドシート](https://sheets.google.com) を開き、新しいスプレッドシートを作成する
2. シート名を **`メニューリスト`** に変更する
3. `メニューリスト` シートのB列に、管理したい種目名を入力する

```
B2: ダンベルプレス
B3: インクラインダンベルプレス
B4: ラットプルダウン
B5: ケーブルフライ
...（以降、追加したい種目を下に追記）
```

---

### Step 2：スプレッドシートIDを確認する

スプレッドシートのURLから **スプレッドシートID** を確認します。

```
https://docs.google.com/spreadsheets/d/【ここがスプレッドシートID】/edit
```

このIDをコピーして控えておいてください。

---

### Step 3：OpenRouter APIキーを取得する

1. [https://openrouter.ai/](https://openrouter.ai/) にアクセスしてGoogleアカウントでログイン
2. 右上のアイコン →「**Keys**」をクリック
3. 「**Create Key**」→ 名前を入力（例：`筋トレ記録`）
4. 表示されたAPIキーをコピーして安全な場所に保存

⚠️ APIキーは他人に見せないでください。チャットやGitHubなどに貼り付けるとキーが自動無効化されることがあります。

---

### Step 4：GASエディタを開く

1. スプレッドシートを開く
2. 上メニュー「**拡張機能**」→「**Apps Script**」をクリック

---

### Step 5：コードを貼り付ける

GASエディタが開いたら、ファイルを2つ作成します。

#### ファイル① `コード.gs`

最初からあるファイルの中身を全て削除し、コードを貼り付けます。

**⚠️ 以下の2箇所を自分の情報に書き換えてください：**

```javascript
const OPENROUTER_API_KEY = 'ここにOpenRouterのAPIキーを貼り付ける'; // ← 書き換え
const SPREADSHEET_ID     = 'ここにスプレッドシートIDを貼り付ける';  // ← 書き換え
```

#### ファイル② `index.html`

GASエディタ左側の「**＋**」ボタン →「**HTML**」を選択 → ファイル名を `index` にします。

中身を全て削除し、index.htmlのコードを貼り付けます。

---

### Step 6：Webアプリとしてデプロイする

1. GASエディタ右上の「**デプロイ**」→「**新しいデプロイ**」をクリック
2. 種類の選択：「**ウェブアプリ**」を選択
3. 以下のように設定する

| 項目 | 設定値 |
| :---- | :---- |
| 説明 | 筋トレ記録v1（任意） |
| 次のユーザーとして実行 | 自分 |
| アクセスできるユーザー | 自分のみ |

4. 「**デプロイ**」ボタンを押す
5. 表示された **WebアプリのURL** をコピーして保存する

---

### Step 7：初回の権限許可

発行されたURLをブラウザで開くと、権限許可の画面が表示されます。

1. Googleアカウントを選択
2. 「**このアプリはGoogleで確認されていません**」と表示されたら →「**詳細**」→「**安全ではないページに移動**」をクリック
3. 「**許可**」をクリック

これで初期設定は完了です！

## 使い方（日々の運用）

### PCの場合

1. デプロイ時に発行された **WebアプリのURL** をブラウザで開く
2. 手書きメモの写真をアップロードする
3. 「**画像を解析してシートに記録する**」ボタンを押す
4. ✅ が表示されたらスプレッドシートを確認する

---

### スマホの場合（推奨：ホーム画面に追加）

**iPhoneの場合：**

1. SafariでWebアプリのURLを開く
2. 下の共有ボタン（□↑）をタップ
3. 「**ホーム画面に追加**」→「**追加**」

**Androidの場合：**

1. ChromeでWebアプリのURLを開く
2. 右上の「⋮」→「**ホーム画面に追加**」

ホーム画面のアイコンをタップするだけで直接アクセスできます。

---

### 同じ日付のシートが既に存在する場合

AIが日付を誤読するなどして既存シートと名前がかぶった場合、**上書きせずに日付入力画面が表示されます。**

```
⚠️「26/6/6」のシートは既に存在します。別の日付を入力してください。

[ 26/6/8        ] ← AIが読んだ日付が初期値としてセットされる
[この日付で登録する]
```

入力欄にはAIが読んだ日付が自動でセットされるので、間違っている部分だけ修正して登録できます。
修正した日付もすでに存在する場合は、再度入力を求められます。

> ⚠️ **セッションは10分間有効です。** 入力画面が出てから10分以上経過した場合は、もう一度画像をアップロードし直してください。

---

### コードを修正した場合の再デプロイ手順

コードを変更した際は以下の手順で更新します。

1. GASエディタ →「**デプロイ**」→「**デプロイを管理**」
2. 鉛筆アイコン（編集）をクリック
3. バージョン：「**新しいバージョン**」を選択
4. 「**デプロイ**」をクリック

URLは変わりません。

## データ入力ルール

AIが画像を読み取る際、以下のルールで自動的にデータを整理します。

### シート名（日付）のフォーマット

手書きメモに書かれた日付は `YY/M/D` 形式でシート名になります。

```
手書き「6/6」 → シート名「26/6/6」
```

### カンマ区切りの回数 → 自動で行分割

```
手書き：  LP / 54kg / 10, 7 / （セット数空欄）

↓ 自動変換後

行1：  LP / 54 / 10 / 1
行2：  LP / 54 /  7 / 1
```

### L表記（ラストセット） → 自動で行分割

```
手書き：  IDP / 16kg / 6回 / 2セット / 備考:L5

↓ 自動変換後

行1：  IDP / 16 / 6 / 2   ← 元の行
行2：  IDP / 16 / 5 / 1   ← L5から生成（セット数は必ず1）
```

### スプレッドシートのデータ構造

| 列 | 項目 | 内容 |
| :---- | :---- | :---- |
| B | メニュー名 | プルダウン付き（メニューリストを参照） |
| C | 重量 | kg単位 |
| D | 回数 | レップ数 |
| E | セット数 | セット数 |

データは2行目をヘッダー行として、3行目以降に書き込まれます。

## トラブルシューティング

### ❌ 「Missing Authentication header」と表示される

OpenRouter APIキーが無効または期限切れです。

1. [https://openrouter.ai/](https://openrouter.ai/) にログインし「**Keys**」から新しいキーを発行する
2. `コード.gs` の `OPENROUTER_API_KEY` を新しいキーに書き換える
3. 再デプロイする

> ⚠️ APIキーをチャットや公開リポジトリに貼り付けると自動無効化されることがあります。

---

### ❌ 「全モデルが失敗しました」と表示される

OpenRouterの無料モデルが一時的にレート制限に達しています。**数分待ってから再度試してください。**

---

### ❌ データが一部抜けている・誤読がある

AIの手書き認識には限界があります。変換後にスプレッドシートと手書きメモを軽く照合することをお勧めします。特に以下の箇所は注意してください。

- 備考欄に複数のL表記がある行
- 同じメニューで重量が変わる行
- 似た数字（例：`6` と `61`、`7` と `1`）

---

### ❌ 「セッションが切れました」と表示される

日付入力画面が表示されてから10分以上経過するとキャッシュが失効します。もう一度画像をアップロードし直してください。

---

### ❌ 「ファイルを開くことができません」と表示される

デプロイ時に発行されたURLが古い可能性があります。「**デプロイを管理**」から最新のURLを確認してください。

---

## 注意事項

- OpenRouter APIの無料枠は **1日200リクエスト・1分20リクエスト** が上限です
- APIキーは絶対に公開リポジトリにコミットしたり、チャットに貼り付けたりしないでください
- 無料モデルのラインナップはOpenRouter側の都合で変更される場合があります
- 日付入力のキャッシュは **10分間** 有効です
